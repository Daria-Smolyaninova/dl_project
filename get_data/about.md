### Основные этапы работы

#### 1. **Парсинг пагинации**
- **Цель**: Получить ссылки на все страницы с памятниками архитектуры
- **Метод**: Используется Selenium для автоматизации браузера
- **Действия**:
  - Открывает главную страницу
  - Определяет количество страниц пагинации
  - Генерирует URL для всех страниц (от 1 до 200)

#### 2. **Сбор ссылок на конкретные памятники**
- **Цель**: Извлечь ссылки на страницы отдельных зданий
- **Метод**: Парсинг HTML-контента каждой страницы пагинации

#### 3. **Обработка данных**
- **Фильтрация**: Удаление дубликатов
- **Нормализация**: Добавление префикса `https://um.mos.ru` к ссылкам на изображения

#### 3. **Сохранение данных**
- **Сохранение**: Скачивание изображений из каждой уникальной страницы здания, вручную добавлены несколько несохранившихся изображений
- **Нормализация**: Изображение сохранено с названием по типу "img_НОМЕР ЗДАНИЯ_ПОРЯДКОВЫЙ НОМЕР ИЗОБРАЖЕНИЯ_НАЗВАНИЕ ЗДАНИЯ.jpg"

### Результат
Получен датасет с более 1800 уникальными памятниками архитектуры Москвы, готовый для дальнейшего анализа. Отдельно скачаны изображения в локальную папку.
